# 2026Omiya

## 概要

Kinectを用いたジェスチャー操作によってオリジナルキャラクターを作成し、対戦・ランキング機能まで楽しめるUnity製アプリケーションです。

ユーザーは頭・胴体・腕・脚の装備を自由に組み合わせてオリジナルアバターを作成できます。作成したキャラクターは保存され、他のキャラクターとの対戦やランキング表示、過去の戦績閲覧が可能です。

本プロジェクトはチーム開発で制作し、私は主にシステム実装・画面遷移・データ管理・UI制御の開発を担当しました。

---

## 主な機能

### アバター作成機能

* 頭・胴体・腕・脚の装備を選択
* 3Dアバターへのリアルタイム反映
* 装備のランダム抽選機能
* 装備プレビュー表示

### Kinect入力

* Kinectによる手の動きを取得
* カーソル操作
* ジェスチャーによる画面操作

### キャラクター管理

* キャラクターデータ保存
* JSON形式による永続化
* 過去に作成したキャラクターの一覧表示
* 詳細情報表示

### バトルシステム

* ステータス計算
* ランダム要素を含む対戦処理
* 勝敗判定
* 戦績保存

### ランキング機能

* 保存された戦績から順位計算
* ランキング画面表示

### 履歴閲覧機能

* 作成済みキャラクターの履歴表示
* 戦績確認
* 詳細ステータス確認

## 工夫した点

### 1. 装備の差し替えシステム

EquipmentMergerを実装し、装備モデルを動的に組み合わせられるようにしました。

### 2. データの永続化

キャラクター情報をJSON形式で保存し、アプリ再起動後も利用できるようにしました。

### 3. UIの状態管理

GameManagerを中心に画面遷移を管理し、複数画面を持つアプリケーションでも保守しやすい構成を意識しました。

### 4. Kinect操作への対応

通常のマウス入力ではなく、Kinectから取得した手の位置情報を利用してUI操作を実現しました。
